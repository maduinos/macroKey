macroKey 문서

8버튼 매크로 키패드. 패드는 앱 없이 USB 키보드/마우스로 동작하고, PC 앱은 설정·녹음할 때만 켭니다.

쓰는 사람

  • 사용 설명서 앱 화면 하나하나, 녹음·재생·프로필
  • 최신 릴리스 내려받기 Windows·Linux 실행 파일. 설치 과정도 Python도 필요 없습니다

만드는 사람 — 배선

  • Pro Micro (ATmega32u4) 배선 가이드 기본 보드. 핀 맵, 버튼 1개 상세, 전체 결선도, 부품 목록
  • ProMicro RP2040 배선 가이드 확장 보드. 매크로 용량 70배

인쇄해서 작업대에 두고 쓰시라고 만든 문서입니다.

설계

  • 지원 보드 보드별 차이, 펌웨어 설치, 새 보드 추가 체크리스트
  • 하드웨어 전력 예산, LED 합성, 부팅 안전장치
  • 시리얼 프로토콜 호스트와 패드가 주고받는 메시지
  • 아키텍처 8개 버튼을 16개 슬롯으로, 메모리 예산, 재생 속도
  • 소스에서 빌드하기 저장소 구조, 개발용 CLI, 릴리스 절차
